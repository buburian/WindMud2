# 玩家角色手冊

這份手冊說明玩家角色的規則：等級、主屬性、種族、公會、HP／MP／MV、物品和裝備、負重、戰鬥的出手順序、戰鬥、技能、身上的效果、雙持，還有定時做的事。
規則是 `mud_design` 定的。數字怎麼推導出來的，見 `mud_design` 的 `design/設計文件.md`
（§2.5 單次攻擊傷害和雙持、§3.2 主屬性、§3.6 初始主屬性、種族與升級成長、§8 面板公式），這裡只寫規則。

每條規則都標了新系統（這個 Python 伺服器）實作了沒：
- ✅ 已實作：伺服器已經在用。
- ⏳ 還沒做：規則定好了，伺服器還沒有。

## 名詞

跟 `mud_design` 設計文件 §2 開頭的名詞表一樣。

| 名詞 | 意思 |
|---|---|
| 主屬性 | STR、INT、WIS、CON、DEX 五項 |
| 次要屬性 | 主屬性以外的數值：HP、MP、MV、物理傷害、法術傷害、命中、閃躲、爆擊率、爆擊傷害、攻速、物理抗性、法術抗性、龍焰抗性、AC |
| 全屬性 | 主屬性加上次要屬性。只是文件用的名詞，不是裝備的加成 |

- 次要屬性裡，HP、物理傷害、法術傷害、命中、閃躲、爆擊率、爆擊傷害、攻速、物理抗性、法術抗性這 10 種，可以用裝備點數買。
- AC 由裝備等級和部位決定；MP、MV 暫時不算點數；龍焰抗性不算點數。

## 建立角色

- 名字用英文 3～12 個字母（照 C 版），大小寫不拘，存成第一個字大寫（`vcx` → `Vcx`）。不能用 all、auto、imm、immortal、self、someone。
- 有這個角色就問密碼，密碼錯就斷線。
- 沒有這個角色就建立：
  1. 設定密碼：至少 5 個字，要打兩次。打密碼時畫面不顯示字。
  2. 選性別：男、女。
  3. 選[種族](#種族)。
  4. 選[公會](#公會)。
  5. 建好：1 級，主屬性先用種族的數字（公會怎麼套上去還沒決定），骰 MP、MV 的倍率，HP、MP、MV 補滿，存檔。
  6. 站在自己那一份[教學學院](#教學學院)的第一間。
- 同一個角色已經在線上，又用對的密碼登入：舊的連線斷掉，新的接手，站在原本的地方。
- 離線時存檔（quit 和直接斷線都存），也可以打 `save`（sav）手動存。存檔也寫一份全部屬性，但讀檔時次要屬性照公式重算。
- `score`（`sc`）看自己的全部屬性：等級、經驗、金幣、主屬性（自己的 ＋ 裝備、效果加的）、HP／MP／MV、次要屬性，身上有效果時列在最下面。
  - 寬 79 格，跟 C 版一樣。每個數字的位置固定：經驗留 7 位數、HP／MP／MV 7 位數、次要屬性 8 位數，金幣放在行尾，數字變長也不會把畫面撐寬。
  - 金幣還沒有拿到的地方，現在都是 0（存檔有這一格）。
  ```
  ===============================================================================
   【Shabu】 人類｜劍之公會｜男
  -------------------------------------------------------------------------------
   等級 1      經驗 35 / 139                       金幣 0
   力量  12   智慧  12   知識  12   體質  12   敏捷  12
  -------------------------------------------------------------------------------
   HP  [====================]       64 / 64
   MP  [====================]       28 / 28
   MV  [====================]       35 / 35
  -------------------------------------------------------------------------------
   攻擊  物理傷害        4       法術傷害        0       命中           16
         爆擊率          8       爆擊傷害        3       攻速           22
   防禦  閃躲           11       物理抗性        8       法術抗性       17
         龍焰抗性        0       AC              0
  ===============================================================================
  ```

## 教學學院

使用者定的（2026-11-06）。區域檔是 `areas/academy.json`（副本，腳本在 `areas/academy/`）。

- 新角色建好就站在自己那一份學院的第一間（學院大門），一個人一份，看不到別人。
- 一路學走路、開門、撿東西、開鎖、技能、穿裝備、打怪：走廊北邊的鐵門鎖著，鑰匙在東邊的儲藏室；
  技能教室的技能教官教 `skills` 看技能、`use` 放技能（照公會說一開始就會的：`use smash dummy`、`use fireball dummy`）；
  教官室的教官送[餽贈](#技能)和一把 1 級紫色長劍（教 `wear`；身上已經有就不再給）；
  訓練場的稻草人一定掉 1 級紫色護甲（教從屍體 `get`），打倒它往畢業廳的石門才打開。房間的描述寫了每一步要打什麼。
- 在畢業廳說 `say 畢業`：院長收回銅鑰匙，送到起始房間，這樣就畢業了。送出來時馬上存檔。
- 還沒畢業：離線再登入、死掉，都回學院的第一間（使用者選的：中途離開就重來）。20 分鐘內回來是同一份學院，門和東西照離開時的樣子。
- 已經建好的舊角色不用上學。是不是學生記在存檔的腳本變數（`vars` 的 `academy` 裡的 `student`）。

## 等級

- 新角色從 Lv1 開始，最高 Lv100。
- 每升一級得到 1 點主屬性點數，玩家自己決定加在哪一項。

### 經驗值

打死生物拿經驗值，滿了自動升級（設計文件 §4.7）：

- 打怪經驗 ＝ 基準值（看玩家等級）× 怪物難度 × 種類加成 ×（1 ＋ 前期經驗加成）。怪物難度 ＝ 種類難度 × 1.30^(怪物等級 − 玩家等級)：
  打高等的怪給得多，每低 1 級 ÷1.30，**低 10 級以上（含）是 0**。玩家的裝備不影響經驗。
  - Lv1 打同級一般怪是 15（沒有前期經驗加成是 10）。
  - Lv20 打同級的：垃圾怪 0.8、一般怪 36.0、菁英怪 85.2、Boss 91.0。
- **前期經驗加成**（2026-11-05 使用者定，跟種類的「經驗加成」×1.2 那種是兩回事）：看玩家的等級，Lv1 是 ＋50%，
  前期減得慢、後期減得快，到 Lv99 是 0。加成(L) ＝ 0.5 ×（1 −（e^(3t) − 1）÷（e^3 − 1）），t ＝（L − 1）÷ 98。
  Lv10 大約 ＋49%、Lv50 大約 ＋41%、Lv70 大約 ＋31%、Lv90 大約 ＋13%。
- 升級需求 ＝ 要打幾隻同級一般怪 × 一隻的經驗（**不算前期經驗加成**）：Lv1 → 2 是 10 隻的量（100 經驗），之後每級多 3.5%，Lv99 → 100 是 300 隻的量。
  因為打怪有前期經驗加成，實際要打的比較少：Lv1 → 2 實際打 6.7 隻；從 1 級到滿級總共 6,998 隻（沒有加成是 8,512 隻）。
- 經驗是「這一級累積了多少」，升級時扣掉這一級的需求，多的留著；一次拿很多可以連升好幾級。升級時 HP、MP、MV 補滿。
- 滿等不再拿經驗。
- 只有打出最後一下的玩家拿經驗（還沒有組隊）。imm 的 `slay` 殺死的不給經驗。
- `score` 的等級那行寫「經驗 35 / 139」：這一級累積的 / 升級要的（滿等不顯示）。
- imm 用 `advance` 改等級時，經驗從 0 開始。

## 主屬性

主屬性有五項：STR 力量、INT 智慧、WIS 知識、CON 體質、DEX 敏捷。

### 創角

- 五項加起來剛好 60，每項最低 8、最高 16。
- 有種族修正時，套上去之後的最終值也要在 8～16、總和 60。

### 升級

- 每升一級 1 點，玩家自己加：`train <屬性> [點數]`，例如 `train str 5` 或 `train 力量`。只打 `train` 看還有幾點。
  沒加的點數會一直留著，`score` 主屬性那行的「可分配」就是它。
- 角色自己的主屬性（創角的加上升級加的）每項最高 55。裝備和 buff 加的不受這個上限。
- 降級（imm 用 `advance` 把等級調低）：要扣的點數先從還沒分配的扣；不夠的，一點一點隨機挑加過點的屬性扣 1。
  創角的數字不會被扣到。
- 55 要大於等於滿等時的[公會](#公會)標準值（現在滿等是 100，劍之公會的標準 CON 大約 52.7），以後改滿等時要一起檢查。

### 主屬性的影響

這裡只寫大概，不寫比例。

| 主屬性 | 影響 |
|---|---|
| STR | 物理傷害、爆擊傷害、命中、MV、[負重](#負重)、能拿多重的武器（[武器重量限制](#武器重量限制)） |
| INT | 法術傷害、爆擊率、命中、MP |
| WIS | 法術抗性、爆擊傷害、HP、MP |
| CON | HP、物理抗性、MV |
| DEX | 閃躲、攻速、爆擊率、命中 |

- 負重、武器重量限制、MP、MV 只看角色自己的主屬性（創角的加上升級加的）。裝備和 buff 加的不算。
- 其他影響，角色自己的和裝備、buff 加的都算。
- 公會用不到的能力沒有效果，例如劍之公會的法術傷害。
- 主屬性換算成能力的數字，會跟著等級和公會變。公式見設計文件 §3.2、§8。

## 種族

玩家有 6 個種族。以人類的 12、12、12、12、12 為基準再加減：每個種族加減合計 0（五項加起來都是 60），每項都在 8～16 之內。

| 種族 | 特色 | STR | INT | WIS | CON | DEX |
|---|---|---|---|---|---|---|
| 人類 | 平均，沒有弱點 | 12 | 12 | 12 | 12 | 12 |
| 精靈 | 聰明、靈巧、體弱 | 10 | 14 | 12 | 11 | 13 |
| 矮人 | 耐打、動作慢 | 13 | 11 | 12 | 14 | 10 |
| 獸人 | 力氣大、不愛動腦 | 14 | 11 | 11 | 12 | 12 |
| 半身人 | 身手敏捷、個子小 | 11 | 12 | 12 | 11 | 14 |
| 靈族 | 精神力強、MP 多、體弱 | 11 | 12 | 14 | 11 | 12 |

- 這是玩家的種族。區域製作手冊裡生物的 [race](區域製作手冊.md#race種族) 是舊版 C 的種族清單，給怪物用，跟這 6 個不是同一套。
- 每個種族有一個種族技能（設計文件 §3.6）：

  | 種族 | 技能 |
  |---|---|
  | 人類 | 交易：賣東西給商店拿到的金幣 ×1.10，向商店買東西付的金幣 ×0.90（商店的價格見區域製作手冊的 [shop](區域製作手冊.md#shop商店)） |
  | 精靈 | 夜視：很暗的地方不用光源也看得見 |
  | 矮人 | 堅韌：中毒這類持續扣血的效果，時間減半（debuff 每 tick 減 2） |
  | 獸人 | 怪力：[負重](#負重)上限 ×1.25 |
  | 半身人 | 不起眼：會主動攻擊的怪物，有一半機率不會主動打他 |
  | 靈族 | 靈視：看得到隱形的東西 |

  除了矮人的堅韌會影響持續扣血的效果（見[身上的效果](#身上的效果)），其他都跟戰鬥無關。
- [公會](#公會)怎麼套在種族上面還沒決定，見[還沒決定](#還沒決定)。

## 公會

遊戲沒有職業。創角時選一個公會（遊戲背景是中古魔法，所以用這種名字）：

| 公會 | 傷害 | 技能的消耗 | 攻擊被哪種抗性擋 |
|---|---|---|---|
| 劍之公會 | 物理傷害 | 物理技能耗 MV | 物理抗性 |
| 杖之公會 | 法術傷害 | 法術耗 MP | 法術抗性 |

- 設計文件和 `mud_design` 的 balance.py 裡，劍之公會的代號是 `phys`，杖之公會是 `spell`。
- 技能、法術由玩家自己學、自己搭配。公會裡再分支，例如劍之公會往賊或坦克、杖之公會往純攻擊或補血。
  稱號照學的技能變，例如杖之公會的賢者。這裡先寫方向；現在有的技能見[技能](#技能)，怎麼學、能學幾個還沒定。
- 公會的標準主屬性（設計文件 §3.6）：

  | 公會 | STR | INT | WIS | CON | DEX |
  |---|---|---|---|---|---|
  | 劍之公會 | 12 | 8 | 8 | 16 | 16 |
  | 杖之公會 | 8 | 12 | 8 | 16 | 16 |

- 公會怎麼套在種族上面還沒決定，見[還沒決定](#還沒決定)。

## HP、MP、MV

- MP 是法術類技能的消耗，MV 是物理類技能的消耗。
- 用武器平砍不消耗。走路也不消耗 MV。
- 上限用「現在的主屬性和等級」直接算出來，不是每升一級累積上去（舊版 Diku 的做法）。主屬性變了，上限整條跟著變。
- 技能每用一次的消耗（設計文件 §2.6）＝ max(1, 四捨五入(這個等級的**公會標準** MV（劍之公會）或 MP（杖之公會）× 技能的消耗比率))。
  - 乘的是公會標準，不是自己的上限：同等級、同公會的人用同一個技能，扣的一樣多。
  - 四捨五入是 .5 進位。畫面上顯示的整數，就是扣掉的數字。
  - MV（MP）不夠就不能用。夠不夠看的是**四捨五入後**的 MV（MP），也就是 prompt 上的數字（使用者選的）：
    prompt 寫 4、消耗 4 就能用，扣完最少是 0。
  - 現在的技能消耗比率都是 10%，每次扣：1 級 4、10 級 6、30 級 15、50 級 37、80 級 152、100 級 387（兩個公會一樣）。
  - 技能本身見[技能](#技能)。

### MP、MV 的上限

兩個公會都有 MP 和 MV（設計文件 §2.6）。不計價，也不進傷害公式，不影響平砍的平衡。

- 公會標準配點時的量：
  - 自己公會用的那種（杖之公會的 MP、劍之公會的 MV）＝ 裸裝 HP × 50%。
  - 另一種（杖之公會的 MV、劍之公會的 MP）：1 級是自己公會那種的 50%，之後每升一級 × 大約 1.034，滿等大約 500。
    一開始就有基本量，而且永遠比自己公會的那種少。
- 實際上限 ＝ 標準的量 × Σ（角色自己的主屬性 ÷ 公會標準）× 負責的比例：
  - MP：WIS 70%、INT 30%。
  - MV：STR 70%、CON 30%。
  - 只看角色自己的主屬性，裝備和 buff 加的不算。
- 創角時骰一次 0.95～1.05 的倍率，這個角色的 MP、MV 上限一直乘上它。MP 和 MV 用同一個倍率。

公會標準配點、倍率 1 時的數字：

| 等級 | 裸裝 HP | 自己公會的資源 | 另一種資源 |
|---|---|---|---|
| 1 | 75 | 38 | 19 |
| 10 | 114 | 57 | 25 |
| 50 | 745 | 372 | 95 |
| 100 | 7,749 | 3,874 | 500 |

### 回復

每 30 tick（30 秒）回復上限的固定比例，HP、MP、MV 都一樣：

| 姿勢 | 每次回復 |
|---|---|
| 站著 | 10% |
| 休息 | 20% |
| 睡覺 | 30% |

- 戰鬥中不回復：戰鬥公式的 1:1 沒有算回血。
- 回復比例跟屬性無關：屬性已經透過上限影響回復量。
- 姿勢就是區域製作手冊的 [position](區域製作手冊.md#position姿勢) 表，用 `rest`、`sleep`、`stand` 改，見[姿勢和指令](#姿勢和指令)。
- 昏迷、快死了這些姿勢手冊沒寫，伺服器先當作不回復。
- 所有在線的玩家一起回（副本裡的也是），由世界 tick 做。prompt 要等下一次出現才看得到新的數字。

## 物品和裝備

指令的訊息照 C 版（act_obj.c）。物品的名字跟找生物一樣：只打開頭就行、同名的用 `2.sword`（見[戰鬥](#戰鬥)的「名字的找法」）。
一個指令的訊息合成一段送：`get all` 撿好幾件，旁邊的人也只看到一次。

- `get <東西>`（`g`）：撿地上的。`get all`：撿地上全部撿得起來的（屍體這種撿不起來的跳過）。
- `get <東西> <容器>`、`get all <容器>`：從屍體或容器（箱子、袋子）裡拿，容器在地上或背包裡都行。屍體本身撿不起來：「你不能拿起這樣東西。」
  容器關著拿不出來：「【箱子/box】關起來了。」
- **容器**：`open`、`close`、`lock`、`unlock` 也能開關、上鎖地上或身上的容器（訊息照 C 版）。
  - 找的順序（使用者選的）：門的名字 → 方向 → 東西，所以 `open n` 一定是北邊的門，`open box` 才是箱子。
  - 上鎖、開鎖要有那個容器的鑰匙：背包裡或身上有那個號碼的物品。門的鑰匙也一樣。
  - 關著的容器 `look in` 看不到裡面：「它是蓋起來的。」
- `drop <東西>`（`dr`）、`drop all`：丟到地上。地上的東西不會自己消失，區域物件釋放時跟著不見。
- `give <東西> <名字>`（`gi`）：把背包裡的東西給同房間的人，玩家或生物都可以（照 C 版，使用者定的）。名字的找法跟 `kill` 一樣。
  - 訊息：「你把【藥水/potion】拿給Hua。」，他收到「Ming把【藥水/potion】拿給你。」，其他人「Ming將【藥水/potion】拿給Hua。」
  - 對方是玩家要放得下：「Hua沒辦法攜帶這麼多的物品。」「Hua沒辦法攜帶這麼重的物品。」（生物不檢查）
  - 店主不收：「商人拒絕拿【藥水/potion】。」，其他人「Ming想要拿【藥水/potion】給商人，但是它拒絕了。」，店主「你拒絕拿Ming的【藥水/potion】。」
  - 沒打東西或名字：「你想把什麼物品給誰？」；沒有那樣東西：「你沒有這樣東西。」；找不到人：「他們不在這裡。」
  - `give <數量> coins <名字>`：給金幣（`coins` 可以縮寫）。1 級不能給：「你的等級不足以給人金幣。」；不夠：「你沒有這麼多金幣。」；
    數量不是正數或不是 coins：「抱歉，你不能這樣做。」。訊息「你給Hua一些金幣。」，他收到「Ming給你【300】枚金幣。」，其他人「Ming給Hua一些金幣。」。
    一次給 100 萬枚以上記 log。生物也收得到金幣，但還不會放進屍體。
  - 給完幫給的人存檔（照 C 版，防止當機時東西變兩份；C 版會印 do_save 的「Ok.」，我們不印）。
  - 還沒做：無法丟棄的物品（drop 也還沒擋）、看不看得到、任務物品。之後的腳本會有「有人給牠東西」（on_give）。
- `wear <東西>`（要打完整：`wea` 是 weather）：穿上，那個部位有東西就先換下來（照 C 版）。
  - `wear all`：背包裡能穿的，穿到**空的**部位（不換下東西）。沒有能穿的：「你沒有可以裝備的東西。」（新加的，C 版什麼都不說）
  - 戒指有兩個位置，先放空的那隻手；兩隻都有就換左手。
  - 雙手武器同時佔主手和副手。副手武器見[雙持](#雙持副手拿武器)。
- `remove <東西>`（`rem`）、`remove all`：卸下來放回背包。什麼都沒穿：「你身上沒有穿任何裝備。」（新加的）
- `inventory`（`i`、`inv`）：看背包，最後一行是件數和負重（使用者選的）：
  ```
  你目前所攜帶的東西有：
       測試藥水/potion
  （1/35 件，負重 9/140）
  ```
- `equipment`（`eq`）：看身上穿的，部位的名稱和順序照 C 版：
  照明用具、左手手指、右手手指、脖子上的、穿在身上、戴在頭上、綁在腿上、穿在腳上、穿在手上、雙手手臂、
  左手盾牌（副手武器是左手武器）、披在身上、圍在腰上、雙手手腕、右手武器（雙手武器是雙手武器）、手中握著。
- `examine`（`ex`、`exam`）：看物品的屬性，**只能看背包裡和身上穿的**（使用者要的），句型照 C 版的 identify。每種東西只列有的那幾行：
  ```
  物品名稱：【疾風之蠻力長劍/sword】，型式：【武器】
  重量：【5】，使用等級：【10】，稀有度：【藍色】
  穿戴部位：【主手】
  武器：【長劍】，攻擊方式：【重砍】
  攻擊力範圍：【12 - 16】（平均【14】）
  加成：力量 +2、攻速 +3
  ```
  - 沒有顏色就不寫稀有度；不是裝備沒有穿戴部位（雙手武器是【雙手】）；有 AC 的護具多一行「防護力：【3】」。
  - 「你想要檢查些什麼？」（照 C 版）；找不到：「你身上沒有這樣東西。」（新加的）
- 地上的物品那一行是區域檔的描述，後面接「/英文名字」（英文亮青，使用者定的）：「一把測試長劍插在地上。/sword」。
- 這些指令要醒著（照 C 版），**打架中可以換裝備**（使用者選的）；`inventory`、`equipment` 什麼姿勢都能看。

### 限制

- **裝備等級**：裝備的等級是可以穿的最低等級（設計文件 §3.4），等級不夠：「你至少等級(Level)要達到【10】級以上才能使用這項物品。」
- **件數、負重**：撿東西、卸下裝備時檢查，見[負重](#負重)。「【X】你不能攜帶這麼多的物品。」「【X】你不能攜帶這麼重的物品。」
- **武器重量**：主手、副手、雙手武器每一把都要比，見[武器重量限制](#武器重量限制)。
  「這把武器太重了，你力量(Str)過小，沒有辦法拿來當武器使用。」
- 生物不穿裝備（使用者說的）；生物撿東西不檢查件數和負重。

### 穿上怎麼影響屬性

照設計文件 §8.2，穿脫裝備時從頭重算全部屬性（不是穿上加、脫下減）：

- 裝備上的次要屬性（含龍焰抗性）直接加上去。
- 裝備上的主屬性用**裝備的等級**換算成次要屬性（舊裝備不會跟著角色升級變強）。公會用不到的不給。
- AC ＝ 全部護具的 AC（含盾牌）。戒指、持握、光源沒有 AC。
- 武器的傷害範圍用在戰鬥，見[戰鬥](#戰鬥)。
- 負重、武器重量、MP、MV 只看角色自己的主屬性，裝備加的不算。`score` 的主屬性顯示「角色 ＋ 裝備」的總和，只是參考。
- 脫下裝備時 HP、MP、MV 夾在新的上限以內。

### 存檔

背包和身上穿的都會存檔，整件存（名字、隨機的屬性、武器的傷害範圍都在裡面）：區域檔之後改了，身上的照舊。死掉不掉東西。

### 管理員：做出物品、看資料

`oload <號碼> [等級] [顏色]`（imm，`ol`）：照區域檔做一件物品，號碼是遊戲號碼，例如 `oload 102 1 white` 是 1 級白色的測試長劍。

- 等級沒寫是自己的等級；顏色寫 gray、white、blue、purple、orange，沒寫就沒有顏色（沒有隨機屬性）。
- 撿得起來的放進自己的背包；撿不起來的放在地上，同房間的人看到「$n創造了【X】！」（照 C 版）。不管件數和負重。

`ostat <名字>`（imm，`os`）：看物品的全部資料（號碼、種類、部位、基本值的小數、加成的代號、點數和上限……）。
找自己的背包、身上、地上、地上屍體裡的（照這個順序）。`ostat <號碼>`：看區域檔裡那件物品原本的寫法。

`mstat <名字>`（imm，`m`）：看同房間的生物或玩家的全部資料（全部屬性的小數、生物的掉落表、玩家的主屬性和經驗……），名字的找法跟 kill 一樣。

`restore <名字>`、`restore all`（imm，`resto`）：HP、MP、MV 補滿，技能的冷卻也清掉（清冷卻是使用者要的，C 版只補滿）。
名字先找同房間的（生物也可以），找不到再找線上的玩家；`all` 是所有在線的玩家。
被補滿的人看到「$n恢復了你身上全滿的狀態。」（照 C 版）。

  |---|---|---|---|---|---|
  | 8 | 100 | 9 | 100 | 10 | 115 |
  | 11 | 115 | 12 | 140 | 13 | 140 |
  | 14 | 170 | 15 | 170 | 16 | 195 |
  | 17 | 220 | 18 | 250 | 19 | 400 |
  | 20 | 500 | 21 | 600 | 22 | 700 |
  | 23 | 800 | 24 | 900 | 25 | 1000 |
  | 26 | 1100 | 27 | 1200 | 28 | 1300 |
  | 29 | 1400 | 30 以上 | 1500 | | |

- 獸人的種族技能「怪力」：負重上限 ×1.25，見[種族](#種族)。
- 超過負重就拿不起來：撿、買、給都一樣。
- 身上穿的裝備也算重量。
- 件數：背包最多 35 件，固定，不看 DEX。身上穿的裝備不算件數。

## 武器重量限制

武器的重量不能超過角色自己 STR 對應的值。數字沿用舊版 `str_app` 表的 wield 欄：

- STR 8～16：就等於 STR，例如 STR 12 能拿重量 12 以下的武器。
- STR 17 以上：

  | 26 | 65 | 27 | 70 | 28 | 75 |
  | 29 | 80 | 30 以上 | 85 | | |

## 戰鬥的出手順序

戰鬥照時間軸出手（設計文件 §2.5）：

- 一回合是 2 tick（2 秒）：打一輪、停一秒。
- 每回合的攻擊次數 A 照攻速公式算，是一回合（2 秒）裡出手幾次。
- 每隻手記「下一次出手的時間」，出手後加上間隔 ＝ 2 秒 ÷ 這隻手每回合出手幾次。
  - 單手：2 ÷ A。
  - 雙持：主手、副手各自算，見[雙持](#雙持副手拿武器)。
- 攻速的小數不用擲骰子：例如間隔 0.8 秒，自然有些回合打 3 下、有些回合打 2 下。
- 開打時雙方的第一下都在第 0 秒。中途加入的人，第一下排在他加入的時間。
- 之後照時間先後出手。同一時間：先動手的人先；同一個人主手先、副手後。
- 每回合把這 2 秒裡的出手照時間排好，依序打出來；停的那一秒不出手。

## 戰鬥

- `kill <名字>`（`k`）：打同房間的生物，牠會自動還手。**不可以打玩家**（自己也不行）。
  休息、睡覺時不能用；已經在打就是「你現在正在為自己的戰鬥努力著!!」。
- **名字的找法**（使用者定的，`kill`、`slay`、`use` 和之後要找生物的指令都一樣）：
  - 跟指令一樣只打開頭就行：`kill do` 就是 dog（生物照區域檔的 `keywords`，玩家照名字；英文不分大小寫）。
  - 同名的用 `n.名字`：`kill 2.dog` 是畫面上第 2 隻對得上 dog 的。順序照 `look`：生物在前、玩家在後，自己排最後。
- 每一下照設計文件 §2.4、§2.5 算：擲命中 →（傷害點數 ＋ 武器基本傷害）×（1 − 抗性減傷）× 等級差修正 → 浮動 → 擲爆擊。
  - 劍之公會打物理傷害、被物理抗性擋；杖之公會打法術傷害、被法術抗性擋。生物照區域檔的 `attack`。
  - **拿武器**：武器基本傷害是那隻手的武器在最小～最大傷害之間取一個值（每一下各自取），不再另外 ±20%（mud_design 確認的）。
  - **空手**：武器基本傷害是 0，每一下 ±20%（照 balance.py 的模擬）。生物有自己的武器基本傷害，也是 ±20%。
- 訊息照 C 版：
  ```
  你使用直拳攻擊野狗，對它造成輕微的擦傷.(3)
  你使用直拳攻擊野狗，爆擊！對它造成普通的傷口!(15)
  你使用直拳攻擊野狗，但是失手了.(0)
  野狗攻擊你，對你造成普通的擦傷.(5)
  野狗已經斷氣，倒在地上死亡了!!
  ```
  - 拿武器時「直拳」換成那把武器的攻擊方式，例如「你使用重砍攻擊野狗」（區域製作手冊[武器的攻擊方式](區域製作手冊.md#武器的攻擊方式)）。
  - 自己打的那句亮綠，被打的那句亮青。括號裡是這一下的傷害（四捨五入）；10 以下用「.」，其他用「!」。
  - 程度看這一下佔對方 HP 上限幾 %：5% 以下「輕微的擦傷」……100% 以下「***致-命-的-創-傷***」，再上去還有三段（照 C 版）。
  - 一回合裡的訊息合成一段送，只補一次 prompt。
- 生物 HP 到 0 就死，留下屍體（見區域製作手冊的[屍體](區域製作手冊.md#屍體)）。
  打死牠的玩家（在同一間房）接著看到屍體裡有什麼（跟 `look in` 一樣，照 C 版）；開了[自動拾取](#設定config)就改成全部拿出來（跟 `get all corpse` 一樣）。
  這幾句跟斷氣、經驗在同一段。
- **玩家 HP 到 0**：看到「你已經含恨死去了」，回到起始房間（還沒從[教學學院](#教學學院)畢業的是學院的第一間），HP 剩 1。不掉東西、不留屍體、不扣經驗（之後設計死亡再改）。
- **戰鬥中不能用走的離開**（照 C 版）：「不行!!你還在戰鬥狀態中!!」，只能用 `flee`。
- `flee`（`f`）：從戰鬥中逃跑（使用者定的）。
  - 成功的機率 ＝ 10% ＋ 70% × DEX ÷ 55，最多 80%。DEX 是自己的 ＋ 裝備加的，55 以上都是 80%。例如 DEX 12 是 25%。
  - 成功：往隨機一個開著的出口跑掉，自己和打自己的都停手。
    看到「你從戰鬥中逃跑了!!」和新的房間；原本房間的人看到「Ming往東邊逃竄(Flee)了!!。」（照 C 版）。
  - 失敗：「你逃跑失敗了。」，還在打。要等 2 秒才能再逃：「你還要等 2 秒才能再逃跑。」（跟技能冷卻一樣每秒減 1，實際等 1～2 秒）。
  - 沒在打架：「你在害怕什麼呢？你沒有在跟任何一個人戰鬥啊。」；門都關著、沒有出口：「這裡沒有可以逃跑的出口！」（不用等）。
  - 不扣經驗（C 版會扣）。休息、睡覺時不能用。
  - `kill` 沒打名字是「你想要攻擊誰？如果苗頭不對，要記得逃跑(Flee)喔!!」（照 C 版）。
- 還沒有：安全區、生物回血、生物主動攻擊、生物逃跑、組隊。技能見[技能](#技能)，裝備見[物品和裝備](#物品和裝備)。

## 技能

規則是設計文件 §2.6。現在有**傷害技能（打一隻）**和**增益技能（放在自己或同房間的玩家身上）**。

- 每個技能有 5 樣東西：種類、目標、效果（比率、打幾次）、消耗、冷卻。也可以限定主手的武器種類。
- 現在的技能：

  | 技能 | 名稱（`use` 用） | 公會的路數 | 一開始就會 | 種類 | 目標 | 打幾次 | 比率 | 冷卻 | 消耗 | 限用武器 | 打中後 |
  |---|---|---|---|---|---|---|---|---|---|---|---|
  | 重擊 | `smash` | 劍之公會 | 劍之公會 | 傷害 | 一隻 | 1 | 120% | 6 秒 | 劍之公會標準 MV × 10% | 不限 | — |
  | 火球 | `fireball` | 杖之公會 | 杖之公會 | 傷害 | 一隻 | 1 | 120% | 6 秒 | 杖之公會標準 MP × 10% | 不限 | 燃燒 |
  | 天雷 | `thunder` | 沒有（照使用的人） | 只有 imm 會 | 傷害 | 一隻 | 1 | 1000% | 0 | 沒有 | 不限 | — |
  | 餽贈 | `gift` | 沒有 | 要用程式加 | 增益 | 自己或同房間的玩家 | — | — | 0 | 沒有 | 不限 | — |
  | 天護 | `aegis` | 沒有 | 要用程式加 | 增益 | 自己或同房間的玩家 | — | — | 0 | 沒有 | 不限 | — |

- **技能自己設計誰會**（使用者定的）：每個技能是下面其中一種。
  - **建立角色就會**：技能自己寫給哪些公會（可以是兩個公會都給）。
  - **要用程式加**：之後的學習、技能書；現在只有 imm 的 `sset`。
- 會的技能存在存檔裡。建立角色時存進「一開始就會」的；之後新增的「一開始就會」技能，已經建好的角色不會自動會。
  舊的存檔沒有這份清單，讀檔時補上自己公會一開始就會的。
- **公會的路數**：決定傷害類型（劍之公會物理、杖之公會法術）、扣 MV 還是 MP、消耗用哪個公會的標準。**不決定誰會**。
  學了別的公會的技能，照樣照技能自己的路數（例如劍之公會學了火球，照樣打法術、照杖之公會標準扣 MP）。使用者：先這樣，做怎麼學技能時再看。
- **只有 imm 會的技能**（使用者要的）：imm 自動會，不能給別人，給管理、測試用。
  - 不是 imm 用了是「你不會這個技能。」，`skills` 也看不到。
  - 傷害類型照**使用的人的公會**（劍之公會物理、杖之公會法術）。
  - 天雷是測試用的，數字是伺服器自己訂的，不是設計文件的。
- **imm 給技能**：`sset <名字> <技能>`（`ss`，照 C 版的名字）學會，`sset <名字> <技能> off` 忘掉。名字是線上的玩家（只打開頭），技能名稱可以縮寫。
  訊息：「Ming 學會了重擊。」，他收到「你學會了重擊！」；忘掉是「Ming 忘掉了重擊。」、「你忘掉了重擊。」。
  只有 imm 會的技能：「天雷只有 imm 會，不能給別人。」
- **imm 用技能**（任何技能都是）：不扣 MV、MP，也不用等冷卻，方便測試。`skills` 的抬頭會寫。
- **用法**（使用者定的）：`use <技能> [名字]`（`us`），例如 `use fireball 3.dog`：用火球打畫面上第 3 隻狗。
  技能不是指令，只能用 `use` 放。休息、睡覺時不能用。
  - 技能名稱可以縮寫，只找你會的技能：`use f dog` 是火球。不會的（別的公會的、imm 的）：「你不會這個技能。」
  - 名字的找法跟 `kill` 一樣：只打開頭、同名的用 `2.dog`，見[戰鬥](#戰鬥)。
  - **沒在打架**：打名字的生物，跟 `kill` 一樣開打（技能那一下馬上打出去）。沒打名字：「你想要攻擊誰？」
  - **打架中**：沒打名字是打現在的對手。打旁邊沒在打的生物，牠會加進來打你，**你平砍還是打原本的對手**（照 C 版）。
    牠已經在打別人的話，就只是被你打到，不改誰打誰。
  - 找不到：「找不到你想攻擊的人。」；是玩家：「你不可以攻擊玩家。」；沒打技能：「你想要用什麼技能？」
  - 冷卻、MV（MP）、武器的檢查都過了才開打：沒過就不會開打。
- 打指令的當下就打出去。平砍照打：技能是額外多打的，不佔平砍的出手。
- 每一次 ＝ 這一下平砍的最終傷害 × 比率：跟平砍一樣擲命中、浮動、抗性、等級差，再各自擲爆擊。
  - 傷害類型是技能的公會（重擊物理、火球法術）。
  - 攻速不影響次數。目標死了，剩下的次數就不打。
  - **打中最低 1 點**（使用者定的）：技能（不是平砍）打中了，傷害再小也算 1 點；失手還是 0。
- **火球的燃燒**（使用者定的）：火球打中（目標沒死）以後，目標身上「燃燒」，每 3 秒燒一次、共 3 次（9 秒），
  每次 ＝ 火球那一下的傷害 × 30%（放下去時算好，最低 1 點）。失手不會燃燒；再中一次火球就重新燒 3 次。
  燃燒是[身上的效果](#身上的效果)的持續扣 HP：護盾先吸收、燒到 0 會死（算被他正在打的對手打死）、矮人的堅韌照算。
  每燒一次：被燒的「你被【燃燒】燒傷了.(6)」（亮青），同房間的人「野狗被【燃燒】燒傷了.(6)」。`skills` 寫「燃燒：每 3 秒 第一發的 30%，3 次」。
- 消耗見 [HP、MP、MV](#hpmpmv)。不夠：「你的 MV 不夠。」（火球是 MP）
- 冷卻：用完要等冷卻的秒數才能再用，每個技能各自算。
  - 世界的 tick 每秒減 1，所以實際等 5～6 秒（看按下去時在 tick 的哪裡）。
  - 還沒好：「你還要等 3 秒才能再用重擊。」
  - 下線就清掉，不存檔。
- **增益技能**（使用者定的）：把一個[效果](#身上的效果)放在自己或同房間的玩家身上，**不會開打**，打架外、打架中都能用。
  - `use gift` 是給自己，`use gift hua` 是給 Hua（名字的找法跟 `kill` 一樣）。打架中沒打名字也是給自己。
  - 找不到：「這裡沒有這個人。」；是生物：「餽贈只能放在玩家身上。」
  - 訊息：「你對自己施展了【餽贈】。」（同房間「Ming對自己施展了【餽贈】。」）；給別人是「你對Hua施展了【餽贈】。」，
    他「Ming對你施展了【餽贈】。」，其他人「Ming對Hua施展了【餽贈】。」
  - 再放一次是覆蓋（時間回到滿的），見[身上的效果](#身上的效果)。
  - NPC 也能放（給之後的教學區用）：生物不用學、沒有冷卻，也不用在打架。
- **餽贈**（使用者定的，之後教學區的 NPC 送給玩家）：每 3 秒補 HP 上限的 10%、五個主屬性各 +3，持續 3600 秒，死掉後還在。
  不扣消耗、沒有冷卻。消失時「你身上的【餽贈】消失了。」
- **天護**（使用者定的）：放一個[護盾](#身上的效果)，HP 上限的 120%，持續 10 秒，死掉後不在。要用程式加（現在用 `sset`），
  不扣消耗、沒有冷卻。再放一次回到滿的。`skills` 寫「護盾 HP 上限的 120%」。消失時「你身上的【天護】消失了。」
- 限用武器：寫了武器種類的技能，主手要拿那種武器（例如之後的背刺只能用匕首），空手不行：「你手上的武器不能用背刺。」
  現在的技能都不限。技能的那一下用主手的武器（雙持也只用主手）。
- 訊息跟平砍一樣（見[戰鬥](#戰鬥)），「直拳」換成技能的名字：
  ```
  你使用重擊攻擊野狗，對它造成普通的傷口!(15)
  你使用火球攻擊野狗，爆擊！對它造成很深的傷口!(24)
  ```
- `skills`（`sk`）：列出你會的技能，什麼姿勢都能看。
  ```
  你會的技能：
    重擊 smash  傷害 2~4  消耗 4 MV  冷卻 6 秒  還要等 3 秒
  ```
  - 傷害：還沒被抗性擋、不含爆擊。
    拿主手武器：（傷害點數 ＋ 主手武器下限／上限）× 比率（設計文件 §2.6）。
    空手：傷害點數 × 比率 × (1 ∓ 20%)，跟實際打的浮動一樣（使用者選的）。四捨五入。
  - 消耗是整數，扣的就是這個數字。
  - 「還要等」只在冷卻中才有。
  - 增益技能不寫傷害，寫持續多久；做什麼放下一行（太長就換行，不超過 79 格）：
    ```
      餽贈 gift  持續 3600 秒  消耗 0  冷卻 0 秒
        每 3 秒 HP +上限的 10%、力量 +3、智慧 +3、知識 +3、體質 +3、敏捷 +3
    ```
  - 不會任何技能：「你還不會任何技能。」
- 還沒有：補血、減益、打一群、生物在打架時用技能。

## 身上的效果

buff（增益）、debuff（減益）都叫「效果」，規則是設計文件 §2.6。玩家和生物都可以有。
現在的效果：[技能](#技能)餽贈、天護放的，和管理員測試用的。其他的效果（有哪些、多強、哪個技能放）還沒定。

- 一個效果可以有四種作用：
  - **暫時加減屬性**：加減次要屬性，跟裝備一樣算進戰鬥。
    HP、MP、MV 的上限變高不補，變低夾住（跟穿脫裝備一樣）。
    主屬性也可以加減：照**被放的人自己的等級**換成次要屬性（跟裝備一樣的換法，裝備是用裝備的等級；使用者定的）。
    加的主屬性不算負重、MP／MV 上限、55 的上限；生物沒有公會，主屬性的加減不算。`score` 的主屬性會算進去。
  - **持續加減 HP、MP、MV**：每 3 秒跳一次，從放下去開始數，放下去那一刻不跳。
    跳幾次 ＝ 持續時間 ÷ 3（無條件捨去），例如 60 秒跳 20 次。加不超過上限；MP、MV 扣到 0 為止。
    每次的量可以是固定的（HP -10），也可以是上限的幾成（HP 上限的 10%，每跳一次照當時的上限算）。
    扣 HP 的效果可以每跳說一句（例如[火球的燃燒](#技能)：「你被【燃燒】燒傷了.(6)」），沒寫就不說（例如測試毒）。
  - **旗標**：例如失明，表在區域製作手冊的 [affected_by](區域製作手冊.md#affected_by身上的效果)。現在只是記號，還沒有作用。
  - **護盾**（使用者 2026-11-06 定的）：寫「HP 上限的幾 %」。放下去那一刻照被放的人的 HP 上限算出幾點，之後上限變了不改：
    100 HP 的人放 120% 的護盾就是 120 點。
    - 受到的傷害先扣護盾，扣完才扣 HP。**全部的傷害**都算：平砍、技能、毒這種持續扣血（扣光護盾才會被扣死）。
    - 身上有好幾個護盾（不同技能放的）：先放的先扣。
    - 扣光了就破了、消失，告訴他「你的【護盾的名字】被打破了。」；時間到也消失。
    - 再放一次（同一個技能）就重新來：回到滿的點數、時間回到滿的。
    - 戰鬥訊息在數字後面寫吸收了幾點：「野狗攻擊你，對你造成普通的擦傷.(5)（吸收 5）」，自己、被打的、旁邊的人都看得到。
    - `score` 最下面、`mstat` 寫「護盾還剩 N 點」。
- 剩下的時間每秒減 1，到 0 就消失（最後那一秒照樣跳）。消失時告訴他：效果有寫自己的話就用它，沒寫就是「你身上的【名字】消失了。」（使用者要的）。
- **矮人的堅韌**：持續扣 HP 的效果，剩下的時間每秒減 2。
  跳的時間點照樣從放下去開始數，所以 60 秒的毒只跳 10 次。其他效果照常。
- **同一個技能放的只有一份**：再放一次是覆蓋，時間回到滿的、跳的時間從頭數。不同技能放的就疊在一起。
- **HP 被扣到 0 會死**：
  - 生物：一樣留屍體。打架中被扣死，算被牠正在打的對手打死，照常給經驗；沒在打架，誰都不給經驗。
  - 玩家：照一般的死亡，見[戰鬥](#戰鬥)。
- **死掉**：每個效果自己設定死掉後還在不在。
- **離線**：時間停住，存進存檔，登入後接著算。
- 打架前可以先放，打完照樣算。
- 身上的效果列在 `score` 最下面（照 C 版，沒有效果就沒有這一段；使用者要的，不另外做指令）。
  一個效果一行：名字、做什麼、還有幾秒。
  ```
   你受到下列效果的影響：
   【      測試毒】 每 3 秒 HP -10                              還有    25 秒
   【    測試祝福】 命中 +10                                    還有    40 秒
  ```
  - 秒數是實際還要等的（矮人身上的毒減得快，秒數也少一半）。
  - 做什麼太長就換行，接在下一行對齊，整行不超過 79 格：
    ```
     【        餽贈】 每 3 秒 HP +上限的 10%、力量 +3、智慧 +3、  還有  3600 秒
                      知識 +3、體質 +3、敏捷 +3
    ```
- **管理員測試用**：`affect <名字> <效果>`（`af`），`affect <名字> clear` 清掉全部。
  名字先找同房間的（生物也可以），再找線上的玩家。`mstat` 最後一行列出身上的效果。
  數字只是測試用，不是設計文件的：

  | 效果 | 作用 | 時間 | 死掉後 |
  |---|---|---|---|
  | `poison` 測試毒 | 每 3 秒 HP -10 | 60 秒 | 不在 |
  | `regen` 測試回復 | 每 3 秒 HP +10 | 60 秒 | 不在 |
  | `bless` 測試祝福 | 命中 +10 | 60 秒 | 還在 |
  | `blind` 測試失明 | 失明 | 30 秒 | 不在 |
  | `shield` 測試護盾 | 護盾，HP 上限的 120% | 10 秒 | 不在 |

- 還沒有：光圈（名字前面的標記）、區域檔生物寫的 affected_by 放到身上。放效果的技能現在只有[餽贈](#技能)。

## 雙持（副手拿武器）

主手、副手各拿一把武器。副手武器怎麼寫，見區域製作手冊的 [wear_flags](區域製作手冊.md#wear_flags拿起來穿在哪裡)。

- **副手武器要先拿主手的武器**（主手是雙手武器也不行）：「你要先拿主手的武器，才能雙持。」
  雙持時要先卸下副手的武器，才能卸主手的：「你要先卸下左手的武器。」（這兩句是新加的，C 版要學雙持技能）

- 主手、副手都吃攻速。每回合的攻擊次數 A 照原本的攻速公式算，再分給兩手：
  - 主手出手 A × 0.70 次。
  - 副手出手 A × 0.3607934055010107 次（大約 36%）。
  - 兩隻手的出手間隔各自算，小數不用擲骰子，見[戰鬥的出手順序](#戰鬥的出手順序)。
- 同一時間主手先、副手後。
- 每一下各自判定命中、爆擊。
- 傷害 ＝（角色的傷害點數 ＋ 這一把的武器基本傷害）×（1 − 減傷）× 等級差修正。副手那一下用副手武器的最小～最大，訊息用副手武器的攻擊方式。
- 打架中換武器：穿上副手武器，副手的第一下在一次出手間隔之後（不是馬上，不然一直換武器就能多打）；脫掉副手武器，副手就不打了。
- 0.70 是定好的。副手的比例是 `mud_design` 算出來的，剛好補回少掉的盾牌 AC，各等級都一樣。
  所以「主手＋盾牌」、「雙手武器」、「雙持」三種一樣強。以後設計文件的參數改了，這個比例可能會變。

## 設定（config）

使用者定的（2026-11-06），寫法和訊息照 C 版 `do_config`、`pagelength`。設定存在存檔裡。

- `config`（`co`，什麼姿勢都能用）：列出設定。開著的亮青、前面是 `+`、名稱大寫；關著的暗青、前面是 `-`、名稱小寫；最後一行是分頁。
- `config +autoloot`、`config -autoloot`（不分大小寫）：開、關自動拾取。**預設關**（照 C 版）。
  - 開著：打死生物後把屍體裡的東西全部拿出來（跟 `get all corpse` 一樣，拿不動照 get 的規則）。
  - 關著：打死生物後給你看屍體裡有什麼。
  - 只有打死牠、而且在同一間房的玩家才會。
- `config lines 數字`：分頁每頁幾行，**19～60，預設 20**（照 C 版）。不打數字是 20；少於 19 不改；超過 60 設成 60。
- **分頁**：一個指令的回覆超過每頁幾行，先送一頁，提示改成「【請按下 (c)繼續, (r)重印本頁, (b)重印上頁, (q)離開, 或 RETURN】：」。
  - Enter、`c`：下一頁；`r`：重看這一頁；`b`：看上一頁；`q`：不看了。最後一頁看完，提示換回一般的。
  - 打別的指令：不看剩下的，指令照常執行（使用者選的；C 版是吃掉）。
  - 只分頁指令的回覆（包括腳本、生物在你指令當下回的話）。別人說話、戰鬥這種主動送來的照樣馬上送，後面補的是分頁的提示（照 C 版）。

## 姿勢和指令

- `rest`（res）坐下休息、`sleep`（sl）睡覺、`stand`（st）站起來。睡覺時打 `rest` 是醒過來坐著休息。
- 戰鬥中不能 rest、sleep、stand。被打的時候會變成戰鬥中，等於被打醒。
- 休息、睡覺時回復比較快，見[回復](#回復)。
- `!`：重複上一個指令（照 C 版，使用者要的），例如打了 `kill dog` 再打 `!` 就再 `kill dog` 一次。`!` 開頭的都算。
  只按 Enter、`!` 本身、分頁的翻頁按鍵不算上一個指令。還沒打過指令：「你還沒有打過指令。」不存檔。

睡覺、休息時能用哪些指令（使用者確認過的判斷，C 版每個指令也有最低姿勢）：

| 指令 | 睡覺 | 休息 | 理由 |
|---|---|---|---|
| 走路 n e s w u d | ✗ | ✗ | 要先 stand 才能走；戰鬥中也不能走，要用 flee（照 C 版） |
| kill、flee | ✗ | ✗ | 要先 stand（照 C 版），見[戰鬥](#戰鬥) |
| use（技能） | ✗ | ✗ | 要先 stand 才能放技能，見[技能](#技能) |
| look（也包括 `look in corpse`） | ✗ | ✓ | 睡著看不到 |
| get、drop、give、wear、remove、examine | ✗ | ✓ | 要醒著（照 C 版）；打架中可以，見[物品和裝備](#物品和裝備) |
| say | ✗ | ✓ | 睡著不能說話 |
| weather | ✗ | ✓ | 睡著看不到天空（照 C 版） |
| open、close、lock、unlock | ✗ | ✓ | 門的指令，要醒著（照 C 版），見區域製作手冊的[門](區域製作手冊.md#門) |
| chat | ✓ | ✓ | 系統頻道 |
| tell、reply | ✓ | ✓ | 跟 chat 一樣是系統頻道（C 版睡著不能被 tell，我們比照 chat） |
| who、score、skills、help | ✓ | ✓ | 系統類 |
| train | ✓ | ✓ | 系統類，只是分配自己的點數（C 版要醒著，我們放寬） |
| quit、save | ✓ | ✓ | 任何時候都能離開、存檔 |

- 做不到時：睡覺是「在你的睡夢中嗎？」，休息是「嗯... 你正在休息耶..。」（照 C 版）。

- look 會照姿勢寫別人：站在這裡、坐在這裡休息、躺在這裡睡覺、正在這裡戰鬥。

## 還沒決定

- 公會怎麼套在種族上面：例如公會再加減一次，或玩家從種族的數字開始自己移動點數。初始主屬性怎麼產生，跟這件一起決定。
- 怎麼學技能（學習、技能書）、能學幾個，學了別的公會的技能怎麼算消耗。見[技能](#技能)。
- 容器裡的東西算不算件數。舊版是算裡面的件數，容器本身不算。
- 雙持時兩把武器的重量怎麼算。舊版是兩把加起來不能超過 wield 欄的值。

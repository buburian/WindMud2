# 秋風城：生物的平常動作（打招呼、定時動作）用 Lua 重寫

2026-11-17 記下，使用者說要做、稍後再做。

## 背景

舊區域（`.are`）的生物有「平常動作」（area2json 的 `actions`）。轉成我們的格式時拿掉了，因為新系統的生物做事只留 special 和 Lua 腳本。

秋風城（`areas/midgaard.json`）原本有 39 個平常動作，去掉重複的是 37 個。這些都跟任務無關，只是讓城裡熱鬧一點：狗會叫、店老闆會打招呼。

## C 版怎麼做（WindSrc）

- **有人走進來**（`act_move.c` move_char）：玩家走進來時，房間裡站著的生物從自己的「走進來」動作中隨機挑一個做。每次都做。
- **定時**（`update.c`）：每個 tick，沒在打架的生物從自己的「定時」動作中隨機挑一個做。
- 怎麼做有三種：
  - 當指令做：例如 `say …`、`bark`。
  - 房間看到。
  - 走進來的人看到。

## 要做的

- 用 Lua 腳本寫：走進來用生物的 `on_enter`，定時用 `on_timer`（例如每 30 秒）。
- 文字照新的背景重寫：龍焚之夜一百年後、百廢待舉，見 mud_design 的 `design/世界觀.md`。生物的名字已經改過，照現在的名字寫。
  - 不要用「:)」這種表情。
  - 對不上新世界的也要改，例如雜貨店的「火把還是水袋」、行醫者的「升到20級以前」。
- `bark`、`sing`、`smile` 是 C 版的指令，我們沒有，要改成寫出來的句子，例如「癩皮小狗對著你汪汪叫。」。
- `builder_area/midgaard.json` 要跟 `areas/midgaard.json` 一起改。
- 完成條件：
  - `uv run python -m mud.areacheck` 沒有問題。
  - 開伺服器實際走進去，看得到招呼和定時的動作。

- 巫師的「幫我個忙 yes or no」、吟遊詩人的「給我礦晶」：這兩句是任務的開頭，等任務一起做。
- 12 個 C 版生物腳本（`ms_*`）：都是任務或系統，例如珠寶店、鐵匠修裝備、裝備銀行、阿里芭芭的任務。
- 13 個戰鬥動作（`fight_actions`）：都是特殊攻擊。

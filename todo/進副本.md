# 進副本：enter 和傳送門

2026-11-19 記下，使用者說要做、稍後再做。

## 現在
- 伺服器能建立、釋放副本（`zones.instance()`），出口不能跨進、跨出副本（`check_files()` 擋）。
- 只有教學學院用到副本（建角時程式直接放進去）。
- 區域製作手冊進度表：「副本區域：用 `enter` 進去、`recall` 出來，一個隊伍一份」⏳。

## 要做
- `enter` 指令。
- 傳送門（CLAUDE.md 寫「之後做成物品」）。
- 跟 [[組隊]] 一起：一個隊伍一份。
- `area` 的「入口」：副本現在寫 `-----`。做好 enter 以後，改成從神殿大廳走到副本入口的路（`zones.find_routes()`）。
  使用者說的：副本的入口跟副本的 recall 點是不同的，不能拿 `area.recall` 當入口。使用者舉的例子：
  - 在世界的房間 30001 放一個傳送門（portal），玩家打 `enter` 就傳到副本的 50001。
  - 副本的 recall 點是 50001（副本裡面）；副本的入口是 30001（放傳送門的那間）。
  - 所以「怎麼走」要找：哪間房放了通到這個副本的傳送門（重置 `O`），走到那間。
- 離開副本（使用者 2026-11-20 定的）：副本裡也放傳送門，用 `enter` 出去（回到入口那間）。副本裡打 `recall` 只會回到副本裡的 recall 點。

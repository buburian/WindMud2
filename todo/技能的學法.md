# 技能的學法（選路、自動學、換路、稱號）

mud_design 2026-11-19 通知（commit 778eb7f，設計文件 §2.6「怎麼學」，使用者定案）。等技能的 6 步做完再做。

1. 選路：到秋風城的公會分館選（mud_design `design/世界觀.md`「公會怎麼對上遊戲」）。
   - Lv10 選大路：戰士公會 → 戰士、盜賊公會 → 刺客、魔法公會 → 元素、牧師公會 → 神官。選了馬上學會那條路 Lv10 的技能。
   - Lv40 回同一間分館選小路。
2. 自動學：選好路以後，升到 20、30……100 級自動學會那一級的技能，不用回分館、不用錢。晚選的一次補齊。
3. 換路：可以，要花金幣。舊路的技能全部忘掉，新路的照現在的等級一次補齊。
4. 技能書：先不做。
5. 稱號：顯示走的路。Lv10～39 是大路的名字，Lv40 起是小路的名字。

還沒定（要做時先問 mud_design，或把提案給它轉給使用者）：換路的價錢、分館裡是哪個 NPC、選路的指令或對話怎麼寫。

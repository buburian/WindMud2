秋風城的冒險者分成兩個大公會：拿劍的**劍之公會**、拿杖的**杖之公會**。建立角色時選一個，一開始就會一個技能，五級再自動學會一個，之後再選自己的職業。十五級、二十五級還會自動學會兩個被動，讓你打完架少休息一點。

- **職業**：到了十級，回秋風城找自己公會的分館，跟導師說出職業的名字（例如說「戰士」），馬上學會第一個技能。
- **進階職業**：到了四十級，回同一間分館，在自己的職業底下再選一個進階職業。
- **提醒**：十級以上還沒選職業、四十級以上還沒選進階職業，每升一級都會提醒你。
- **自動學**：選好職業以後，每升十級就自動學會下一個技能，不用回分館，也不用花錢。晚一點選也沒關係，會一次補齊。
- **換職業**：可以換，要花金幣。原本那個職業的技能全部忘掉，新的技能照你現在的等級一次補齊。
- **稱號**：顯示你的職業，選了進階職業以後顯示進階職業的名字。
- **MV、MP**：劍之公會的技能用 MV，杖之公會的用 MP。打架中不會回，一場打下來只夠放幾次，要挑時機用。
- **連動**：有些技能一起用會更強，寫在每個職業的最後。

```
劍之公會
├─ 戰士（十級，戰士公會）
│   ├─ 巨武（四十級）
│   └─ 盾衛（四十級）
└─ 刺客（十級，盜賊公會）
    ├─ 雙刃（四十級）
    └─ 暗殺（四十級）

杖之公會
├─ 元素（十級，魔法公會）
│   ├─ 烈焰（四十級）
│   └─ 寒冰（四十級）
└─ 神官（十級，牧師公會）
    ├─ 治療（四十級）
    └─ 詛咒（四十級）
```

## 劍之公會

近身拿武器打的人。龍焚之後，戰士、盜賊、格鬥家的老公會撐不下去，結成了劍之公會。十級時到**戰士公會**選戰士，或到**盜賊公會**選刺客。

- `一開始就會` **重擊**：用力砸下去的一擊，一定打中，而且一定是爆擊。
- `五級` **猛擊**：連續猛擊兩下，每一下都一定打中、一定是爆擊。可以跟重擊輪流用。
- `十五級` **調息（被動）**：休息、睡覺的時候，HP、MV、MP 都回得更快。
- `二十五級` **收刀（被動）**：打完一場架，馬上回一點 HP、MV、MP。

### 戰士（戰士公會，十級～三十級）

正面硬打的職業。學會用盡全力的一擊、鼓舞同伴的吼聲，身體也越練越結實。四十級可以選巨武或盾衛。

- `十級` **猛力斬**：用盡全力砍一刀，傷害很高。
- `二十級` **戰吼**：大吼一聲，讓自己或同伴力氣變大一陣子。
- `三十級` **鋼鐵之軀（被動）**：身體更耐打，HP 上限變高。

連動：

- **戰吼助威**：身上有戰吼時，重擊、猛擊、猛力斬更痛。

#### 巨武（戰士的進階職業，四十級～一百級）

扛著雙手大武器，一刀砍一片。房間裡的怪越多越好打。大部分技能要拿雙手武器：大劍、戰斧、戰鎚、長槍。

- `四十級` **橫掃**：雙手武器橫掃，砍到房間裡所有敵人。
- `五十級` **重武精通（被動）**：拿雙手武器時，平砍更痛。
- `六十級` **旋風斬**：原地轉一圈連砍，打到房間裡所有敵人。
- `七十級` **狂暴**：一段時間內力氣大增，但是防禦變差。
- `八十級` **震地**：重砸地面，震傷所有敵人，還讓牠們站不穩。
- `九十級` **裂空斬**：一刀劈過整個房間，打到所有敵人。
- `一百級` **天崩地裂**：連續重劈，每一下都打到所有敵人。

連動：

- **狂暴連斬**：狂暴的時候，旋風斬、天崩地裂多砍一下。
- **震地破綻**：先用震地讓敵人站不穩，再用裂空斬會特別痛。

#### 盾衛（戰士的進階職業，四十級～一百級）

拿著盾站在最前面。把怪引到自己身上，替同伴擋下傷害。一個人打也撐得住，組隊時最有用。

- `四十級` **挑釁**：讓一隻敵人改打你。
- `五十級` **盾牌精通（被動）**：拿盾的時候，盾擋得更多。
- `六十級` **守護**：一段時間內，替一個同伴擋下一部分傷害。
- `七十級` **盾擊**：用盾撞過去，把敵人撞暈。
- `八十級` **群體挑釁**：讓房間裡所有敵人都改打你。
- `九十級` **鐵壁**：舉起盾牌，給自己一層護盾。
- `一百級` **不倒之盾**：一小段時間內，替同房間的所有同伴分擔傷害。

連動：

- **挑釁盾擊**：對被你挑釁的敵人用盾擊，牠會暈得更久。
- **鐵壁護人**：有鐵壁的時候替同伴擋傷害，自己受的傷比較少。

### 刺客（盜賊公會，十級～三十級）

從暗處下手的職業。背刺要拿匕首，毒讓敵人慢慢流血，身手也越來越靈活。四十級可以選雙刃或暗殺。

- `十級` **背刺**：用匕首從背後刺進要害，傷害很高。要拿匕首。
- `二十級` **身輕如燕（被動）**：身手變靈活，比較容易閃開攻擊。
- `三十級` **毒刃**：讓敵人中毒，慢慢扣血。

連動：

- **毒上加刺**：背刺中毒的敵人更痛。

#### 雙刃（刺客的進階職業，四十級～一百級）

兩手各拿一把武器，一口氣砍出很多刀。技能都要兩手各拿一把武器。跟毒刃一起用最兇。

- `四十級` **雙刃斬**：左右手交替，連砍好幾刀。
- `五十級` **雙持精通（被動）**：副手出手更頻繁。
- `六十級` **疾風連刺**：很快地連刺很多下。
- `七十級` **迴旋刃**：雙刀一轉，砍到房間裡所有敵人。
- `八十級` **致命節奏（被動）**：更容易打出爆擊。
- `九十級` **百裂刃**：一口氣砍出一大串刀。
- `一百級` **刃舞**：在敵人中間連砍很多下，打到所有敵人。

連動：

- **多刀催毒**：連砍的技能每砍中一下，敵人身上的毒就多發作一次。
- **毒刃擴散**：迴旋刃會把一個敵人身上的毒，傳給其他被砍到的敵人。

#### 暗殺（刺客的進階職業，四十級～一百級）

先讓敵人動不了、變弱，再一擊解決。打暈、煙霧、致殘都在這裡；開打前的絕命刺最致命。

- `四十級` **擊暈**：往後腦一敲，把敵人打暈。
- `五十級` **弱點標記**：看穿敵人盔甲的縫隙，讓牠更容易被打痛。
- `六十級` **封喉**：勒住喉嚨，讓敵人一陣子不能用技能和特殊攻擊。
- `七十級` **絕命刺**：還沒開打時才能用的致命一擊，傷害最高。要拿匕首。
- `八十級` **煙霧彈**：丟出煙霧，讓房間裡所有敵人看不清楚，很難打中人。
- `九十級` **致殘**：割斷筋腱，讓敵人打不準、也閃不開。
- `一百級` **影縛**：用影子纏住敵人，讓牠很久不能動。

連動：

- **趁暈絕命**：敵人被打暈的時候，打架中也能用絕命刺。
- **煙中背刺**：背刺看不清楚的敵人（煙霧彈）特別痛。

## 杖之公會

用法術的人。魔法、牧師、心靈師、召喚師、造物師的老公會一起結成了杖之公會。十級時到**魔法公會**選元素，或到**牧師公會**選神官。

- `一開始就會` **火球**：丟出一團火球，一定打中，而且一定是爆擊，還會燒一陣子。
- `五級` **火焰箭**：連射兩支燃燒的箭，每一支都一定打中、一定是爆擊，還會燒一陣子。可以跟火球輪流用。
- `十五級` **冥想（被動）**：休息、睡覺的時候，HP、MV、MP 都回得更快。
- `二十五級` **回神（被動）**：打完一場架，馬上回一點 HP、MV、MP。

### 元素（魔法公會，十級～三十級）

用魔法打人的職業。射出閃電、侵蝕敵人的魔法防護、讓敵人變慢。四十級可以選烈焰或寒冰。

- `十級` **閃電箭**：從指尖射出閃電，傷害很高。
- `二十級` **元素侵蝕**：讓敵人的魔法防護變弱，法術打牠更痛。
- `三十級` **緩速術**：讓敵人的動作變慢。

連動：

- **侵蝕連鎖**：閃電箭打到被侵蝕的敵人，會再跳到另一個敵人身上。

#### 烈焰（元素的進階職業，四十級～一百級）

火的力量。一次燒一整群，讓敵人一直燒；正在燒的敵人，還能一口氣引爆。

- `四十級` **火焰衝擊**：火浪往外推，燒到所有敵人，還讓牠們一直燒。
- `五十級` **引燃**：讓一個敵人從裡面燒起來，慢慢扣血。
- `六十級` **火雨**：天上落下火雨，打到所有敵人好幾下。
- `七十級` **爆炎**：房間中間炸開一團火，打到所有敵人。
- `八十級` **餘燼**：火星落在每個敵人身上，讓牠們都燒起來。
- `九十級` **炎柱**：地上噴出火柱，打到所有敵人，還讓牠們燒起來。
- `一百級` **焚天**：整片天空燒起來，連打所有敵人好幾下，還讓牠們一直燒。

連動：

- **爆炎引爆**：爆炎打到正在燒的敵人，剩下的火會一口氣燒完。
- **火雨添柴**：火雨打到正在燒的敵人，火會燒得更久。

#### 寒冰（元素的進階職業，四十級～一百級）

冰的力量。凍住、變慢，讓敵人碰不到你；凍住的敵人，再一口氣打碎。

- `四十級` **冰錐**：射出一根尖冰，打中以後讓敵人變慢。
- `五十級` **冰凍術**：把一個敵人凍住，不能動。
- `六十級` **寒氣**：讓敵人冷得發抖，很難閃開攻擊。
- `七十級` **冰環**：寒氣往外擴散，凍住房間裡所有敵人。
- `八十級` **暴風雪**：颳起暴風雪，讓所有敵人的動作變慢。
- `九十級` **冰河衝擊**：整片冰河壓下來，打到所有敵人。
- `一百級` **絕對零度**：把一個敵人凍住很久。

連動：

- **慢了就凍**：冰凍術凍住變慢的敵人，凍得更久。
- **碎冰**：冰河衝擊打到凍住的敵人特別痛。

### 神官（牧師公會，十級～三十級）

用神的力量治傷的職業。替自己和同伴補血、祝福。四十級可以選治療或詛咒。

- `十級` **治療術**：治好自己或同伴的傷。
- `二十級` **祝福**：讓自己或同伴更擋得住攻擊，效果持續很久。
- `三十級` **回春術**：讓傷口慢慢癒合，一段時間內一直補血。

連動：

- **回春加護**：對身上有回春術的人用治療術，補得更多。

#### 治療（神官的進階職業，四十級～一百級）

隊伍的依靠。補一個人、補一整群人，還能給護盾，讓同伴撐得更久。

- `四十級` **快速治療**：很快地補一點血，可以很常用。
- `五十級` **神聖護盾**：給自己或同伴一層光罩，先擋下傷害。
- `六十級` **群體治療**：治好身邊所有同伴。
- `七十級` **強效治療**：一口氣治好重傷。
- `八十級` **神佑**：讓自己或同伴的 HP 上限變高，效果持續很久。
- `九十級` **生命之泉**：腳下湧出泉水，讓身邊所有同伴一直補血。
- `一百級` **神蹟**：一次大量治好身邊所有同伴。

連動：

- **群體回春**：群體治療會讓大家身上的回春術、生命之泉重新開始。
- **神佑護盾**：身上有神佑的人，拿到的神聖護盾更厚。

#### 詛咒（神官的進階職業，四十級～一百級）

讓敵人變弱、慢慢腐爛，還能叫出骷髏和死亡騎士替你作戰。

- `四十級` **衰弱術**：讓敵人全身沒力，打人沒那麼痛。
- `五十級` **腐蝕術**：讓敵人的身體慢慢爛掉，一直扣血。
- `六十級` **喚骨術**：叫出一具骷髏替你作戰。
- `七十級` **詛咒術**：讓厄運纏上敵人，牠更容易被打痛。
- `八十級` **吸取生命**：打傷敵人，把一部分傷害吸回來補自己。
- `九十級` **瘟疫**：讓房間裡所有敵人染上疾病，慢慢扣血。
- `一百級` **死亡騎士**：喚醒一位倒下的騎士替你作戰，比骷髏強得多。

連動：

- **越弱越吸**：敵人身上被放的減弱效果越多，吸取生命越痛。
- **死者為僕**：被腐蝕術、瘟疫扣死的敵人，會多變出一具你的骷髏。
